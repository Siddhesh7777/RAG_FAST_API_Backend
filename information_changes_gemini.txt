Change 3B — Added extract_text() Helper Function

• Code added:python
def extract_text(content) -> str:
    if isinstance(content, str):
        return content
    if isinstance(content, list):
        return "".join(
            block.get("text", "") if isinstance(block, dict) else str(block)
            for block in content
        )
    return str(content)
Use code with caution.
• Why: Unlike older LLMs where response.content is a plain str (e.g., "The answer is 42"), Gemini 3.x models return .content as a list of content blocks (e.g., [{'type': 'text', 'text': 'The answer is 42'}], plus internal thinking or tool-call blocks). This function safely extracts and joins only the "text" values into a standard str.

• Before:python

• After:python
def chat_node(state: AgentState):
    messages = [SystemMessage(content=AGENT_PROMPT)] + state["messages"]
    response = llm_with_tools.invoke(messages)
    if response.content:
        response.content = extract_text(response.content)
    return {"messages": [response]}
Use code with caution.
• Why:
	1. LangGraph persists response (AIMessage) into checkpoints.db (SQLite). Converting response.content from a list to a str ensures clean string history in your database.
	2. The if response.content: check ensures we do not touch response when the model makes a tool call (rag_tool), where .content is empty and .tool_calls contains the function call.

Step 5: Changes Made in app/main.py


Change 5A — Fixed AttributeError: 'list' object has no attribute 'encode' in POST /chat

• Before:python
for chunk, meta in events:
    if (
        isinstance(chunk, AIMessageChunk)
        and chunk.content
        and meta.get("langgraph_node") == "chat"
    ):
        yield chunk.content
Use code with caution.
• After:python
for chunk, meta in events:
    if (
        isinstance(chunk, AIMessageChunk)
        and chunk.content
        and meta.get("langgraph_node") == "chat"
    ):
        text = extract_text(chunk.content)
        if text:
            yield text
Use code with caution.
• Why:
	1. Why it crashed before: With stream_mode="messages", LangGraph streams AIMessageChunk objects token-by-token while Gemini is generating (before chat_node finishes). Each chunk.content is a list. FastAPI's StreamingResponse expects str or bytes so Starlette can call chunk.encode("utf-8"). Passing a list caused AttributeError: 'list' object has no attribute 'encode'.
	2. Why extract_text(chunk) didn't work at first: Passing the whole chunk (AIMessageChunk object) fell through to str(chunk) and streamed raw object text. Passing chunk.content extracts only the inner text blocks.
	3. Why if text: was added: Some streamed chunks from Gemini 3.5 Flash-Lite contain only tool-call arguments or thinking metadata with no "text" key, causing extract_text(chunk.content) to return "". Skipping empty strings prevents blank frames from being sent over the stream.
